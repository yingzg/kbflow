# KBFlow Prompt 文档

本目录是 KBFlow 的「流程定义」——每个阶段一份独立 md 文档，供 AI IDE（opencode / codex / claude code）逐阶段执行。

## 分工边界（核心约定）

- **脚本做事实**：扫描器提取类名、注释、方法、表结构、依赖关系——确定的，脚本一次跑完。
- **AI 做语义**：把入口聚类成领域、给入口评分、补写服务概述——需要理解，由 AI 完成。

## 读写约定（省 token + 防错）

- **读**：直接读 `.toon` 文件。toon 是紧凑格式，比 json 省大量 token。
- **写**：AI 输出 **json**，用 `json2toon` 命令转成 toon 落盘。不要手写 toon（容易写错）。

## 上下文隔离（重要）

每个阶段**开一个新窗口**执行，不要在一个窗口里串多个阶段：

- 阶段间靠**产物文件交接**（上一阶段的产物落在 `<输出目录>/service-meta/` 或领域目录，下一阶段读文件）
- 每个窗口只读「当前阶段 + 上一阶段的产物」，上下文短、不溢出
- 这正是「阶段化」的意义：AI 上下文有限，串 8 阶段会溢出，必须每阶段独立窗口

## 用法

在 AI IDE 里，**每个阶段开一个新窗口**，`@` 该阶段的 md 文档：

```bash
# 窗口 1：K01 事实扫描
@kbflow/prompts/K01-事实扫描.md
# 执行完，关闭窗口

# 窗口 2：K02 领域划分（读 K01 产物）
@kbflow/prompts/K02-领域划分.md
# 执行完，关闭窗口

# ... 依此类推，直到 K08
```

断点续跑：某阶段产物已存在则跳过，从中断的阶段继续。
