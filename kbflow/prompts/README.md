# KBFlow 构建流程（总入口）

你现在是 KBFlow 的构建执行者。目标：把一个 Java 项目转成结构化领域知识库。

## 执行方式（最重要）

按 **K01 → K08** 的顺序逐阶段执行。每个阶段：

1. 读该阶段的 md 文档（`K01-事实扫描.md` → `K02-领域划分.md` → ...）
2. 严格按文档执行（调脚本 + AI 语义）
3. 阶段完成，输出「✅ 第 X 阶段完成」，**停下来等用户按 Enter**
4. 用户按 Enter 后，进入下一阶段

**每个阶段执行完必须停下来等用户确认，不要一口气跑完所有阶段。**

## 上下文管理

每个阶段只读该阶段需要的产物文件，不要把所有阶段的产物都塞进上下文。阶段完成后，输出简短的「本阶段产出摘要」，等用户确认后再进入下一阶段。

## 开始前先确认

先问用户两个信息（已给过就跳过）：

1. **项目路径**：要构建的 Java 项目路径
2. **输出目录**：知识库产物输出到哪（默认 `kb`）

## 阶段顺序

| 阶段 | 文档 | 说明 |
|---|---|---|
| K01 | `K01-事实扫描.md` | 纯脚本 scan，提取事实 |
| K02 | `K02-领域划分.md` | AI 聚类领域 + 分类入口，🛑 人工确认领域 |
| K03 | `K03-边界确认.md` | AI 四维评分，🛑 人工复核低置信度 |
| K04 | `K04-领域知识.md` | skeleton 骨架 + AI 补服务概述 |
| K05 | `K05-跨服务链路.md` | 领域总览 + 跨服务链路 |
| K06 | `K06-服务元信息.md` | 服务定位 + 技术配置 + 开发规范 |
| K07 | `K07-全局导航.md` | 全景图 + AI 索引 |
| K08 | `K08-可读性交付.md` | glossary + 自然语言概述 |

## 断点续跑

如果某阶段的产物文件已存在，跳过该阶段，直接进入下一阶段。

## 开始

确认项目路径和输出目录后，读 `K01-事实扫描.md` 开始执行。
