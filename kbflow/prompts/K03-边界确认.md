# K03 边界确认

## 目标

对 K02 的入口归属做四维评分，找出低置信度（可能归错领域）的入口，交人工复核。

## 读什么

- `<输出目录>/service-meta/behavior.toon`
- `<输出目录>/service-meta/domain_division.toon`（含边界矩阵 + 入口归属）

## 步骤

### 第 1 步：四维评分（AI 语义）

对每个入口，用四维权重打分：类名语义 35 / 注释+方法 25 / 包路径 20 / 边界对比 20。

每个入口输出：`entry_id`、`score`（0-100 整数）、`decision`（KEEP/MOVE/DELETE）、`target_domain`、`reason`。score < 70 表示归属不明确。

输出 json：

```bash
python kbflow.py json2toon --json-file 评分结果.json --out <输出目录>/service-meta/reviews.toon --wrap reviews
```

json 结构：

```json
[{"entry_id":"API-003","class_name":"TransferController","score":45,"suggested":"MOVE","target_domain":"库存","decision":"","reason":"包路径与注释冲突"}]
```

### 第 2 步：生成复核清单（脚本）

```bash
python kbflow.py checklist gen --reviews <输出目录>/service-meta/reviews.toon --out <输出目录>/service-meta/review_checklist.md
```

### 🛑 第 3 步：人工填写复核清单

打开 `review_checklist.md`，让用户对每条低置信度条目填「最终决定」（KEEP / MOVE / MOVE:领域名 / DELETE，留空=采纳建议）。改完后继续。

### 第 4 步：解析决定（脚本）

```bash
python kbflow.py checklist parse --checklist <输出目录>/service-meta/review_checklist.md --out <输出目录>/service-meta/review_decisions.toon
```

### 第 5 步：回写领域划分（AI 拼装）

把决定回写到 `domain_division.toon` 的 `domain_mapping`：MOVE 改 `domain_ref`，DELETE 归入 `D99`。

## 输出

`<输出目录>/service-meta/review_decisions.toon` + 更新后的 `domain_division.toon`

## 门禁

决定数 = 入口数，数量守恒。
