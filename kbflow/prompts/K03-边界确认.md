# K03 边界确认

## 目标

对 K02 的入口归属做四维评分，找出低置信度（可能归错领域）的入口，交人工复核。

## 读什么

- `<输出目录>/service-meta/behavior.toon`
- `<输出目录>/service-meta/domain_division.toon`

## 流程

### 1. 调 skill-01 四维评分

打开 `K03-边界确认/skill-01-四维评分.md`，按它给每个入口评分，产出 `reviews.toon`。

### 2. 生成复核清单（脚本）

```bash
python3 .kbflow/kbflow.py checklist gen --reviews <输出目录>/service-meta/reviews.toon --out <输出目录>/service-meta/review_checklist.md
```

### 🛑 3. 人工填写复核清单

打开 `review_checklist.md`，让用户对每条低置信度条目填「最终决定」（KEEP / MOVE / MOVE:领域名 / DELETE，留空=采纳建议）。改完后继续。

### 4. 解析决定（脚本）

```bash
python3 .kbflow/kbflow.py checklist parse --checklist <输出目录>/service-meta/review_checklist.md --out <输出目录>/service-meta/review_decisions.toon
```

### 5. 回写领域划分

把决定回写到 `domain_division.toon` 的 `domain_mapping`：MOVE 改 `domain_ref`，DELETE 归入 `D99`。

## 输出

`review_decisions.toon` + 更新后的 `domain_division.toon`

## 门禁

决定数 = 入口数，数量守恒。
