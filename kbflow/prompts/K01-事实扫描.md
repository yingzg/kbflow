# K01 事实扫描

## 目标

扫描 Java 项目，提取全部「确定性事实」：业务入口、类依赖、拓扑、表结构、缓存键、Mapper 表映射。

## 执行

如果用户还没提供项目路径和输出目录，先问用户这两个信息。然后执行：

```bash
python kbflow.py scan <项目路径> -o <输出目录>
```

这一步**纯脚本，不调用 AI**。脚本内部做完整性校验（入口数量守恒），产出全部事实文件。

## 输出（写入 `<输出目录>/service-meta/`）

| 文件 | 内容 |
|---|---|
| `behavior.toon` | 业务入口（dubbo/rest/mq/job × 有注释/无注释） |
| `topology.toon` | 类依赖拓扑（内部边 + 外部边） |
| `ddl.toon` | 表结构（从真实数据库或 DDL 提取） |
| `key_templates.toon` | 缓存键模板 |
| `mapper_tables.toon` | Mapper 类 → 表名映射 |
| `external_dependencies.toon` | 外部依赖（Maven 坐标等） |

## 门禁

脚本打印入口数。若入口数为 0，检查项目路径是否正确。
