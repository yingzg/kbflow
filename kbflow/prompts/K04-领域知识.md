# K04 领域知识

## 目标

为每个领域生成 3 份文档：服务概述、接口链路、数据模型。先由脚本生成骨架（语义字段留 `[待AI补充]`），再由 AI 补语义。

## 读什么

- `<输出目录>/service-meta/` 下的 behavior / topology / ddl / mapper_tables / domain_division

## 流程（对每个领域 × 每个服务循环）

### 1. 生成骨架（脚本，3 条命令）

```bash
python kbflow.py skeleton overview --domain <领域名> --service <服务名> -o <输出目录>
python kbflow.py skeleton interface --domain <领域名> --service <服务名> -o <输出目录>
python kbflow.py skeleton data-model --domain <领域名> --service <服务名> -o <输出目录>
```

### 2. 调 skill-01 补服务概述语义

打开 `K04-领域知识/skill-01-补服务概述.md`，按它补全 `01-服务概述.toon` 的语义。

### 3. 接口链路 + 数据模型

`02-接口链路.toon` 由脚本生成，无需 AI 补语义。

`03-数据模型.toon` 的 `table_class_map[].comment`（表业务注释）需 AI 补：读表名 + DDL，给每张表一句话业务注释（说清这张表存什么业务数据），输出完整 json 覆盖回 `03-数据模型.toon`。

## 输出

`<输出目录>/<领域>/<服务>/01-服务概述.toon`、`02-接口链路.toon`、`03-数据模型.toon`

## 门禁

服务概述和数据模型的 `[待AI补充]` 全部补全（无残留）。
