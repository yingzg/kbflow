# KBFlow 启动文档

这是 KBFlow 的启动入口。**同步完成后**（知识库目录的 `.kbflow/` 已就绪），按下面的流程开启 K01-K08 构建。

## 怎么开启

**每个阶段开一个新窗口**（AI IDE 会话），`@` 对应阶段的文档。阶段间靠产物文件交接，每个窗口只跑一个阶段。

## 第一阶段（K01 事实扫描）

在 AI IDE 开新窗口，输入：

```
@<知识库目录>/.kbflow/prompts/K01-事实扫描.md

项目路径：<你的 Java 项目路径>
输出目录：<知识库目录>
```

AI 读 K01 文档后，会执行 `scan` 命令，产物落盘到 `<知识库目录>/service-meta/`。执行完报告「✅ K01 完成」，然后关闭这个窗口。

## 后续阶段（K02-K08）

每个阶段关窗口、开新窗口，`@` 对应文档。**不用再附项目路径**（产物已在知识库目录里）：

```
# 窗口 2：@<知识库目录>/.kbflow/prompts/K02-领域划分.md
# 窗口 3：@<知识库目录>/.kbflow/prompts/K03-边界确认.md
# 窗口 4：@<知识库目录>/.kbflow/prompts/K04-领域知识.md
# ... 直到 K08
```

## 阶段清单

| 阶段 | 文档 | 谁做语义 |
|---|---|---|
| K01 | `K01-事实扫描.md` | 无（纯脚本） |
| K02 | `K02-领域划分.md` | AI 聚类 + 分类，🛑 人工确认领域 |
| K03 | `K03-边界确认.md` | AI 四维评分，🛑 人工复核低置信度 |
| K04 | `K04-领域知识.md` | AI 补服务概述 |
| K05 | `K05-跨服务链路.md` | AI 补领域总览 |
| K06 | `K06-服务元信息.md` | AI 补服务定位 |
| K07 | `K07-全局导航.md` | AI 汇总索引 |
| K08 | `K08-可读性交付.md` | AI 写叙述 + 术语表 |

## 上下文隔离

每个窗口只跑一个阶段、只读「当前阶段 + 上一阶段产物」。AI 上下文有限，串 8 阶段会溢出，必须每阶段独立窗口。

## 断点续跑

某阶段产物文件已存在则跳过，从断点阶段继续。
