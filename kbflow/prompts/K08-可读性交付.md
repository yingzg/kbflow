# K08 可读性交付

## 目标

把每个领域的结构化事实，转成「人可读」的自然语言文档：业务名词解释（glossary）+ 自然语言概述。

## 读什么

- `<输出目录>/service-meta/` 下的 behavior / ddl / domain_division
- `<输出目录>/<领域>/<服务>/` 下的 3 份领域知识文档

## 步骤（对每个领域循环）

### 第 1 步：事实密封（脚本）

```bash
python kbflow.py seal --domain <领域名> --service <服务名> -o <输出目录>
```

脚本输出该领域的结构化事实清单（入口清单 + 表清单）。这些是「不可改动的事实」。

### 第 2 步：写业务名词解释（AI）

读入口清单 + 关键实体，提取业务名词，给每个名词一句话中文解释（说清楚它是什么，不是做什么）。输出 json：

```bash
python kbflow.py json2toon --json-file glossary.json --out <输出目录>/<领域>/<服务>/_glossary.toon --wrap glossary
```

### 第 3 步：写自然语言概述（AI）

基于事实清单，写两段叙述：一句话定位 + 一段服务概述（负责什么、核心链路是什么）。**禁止改动事实清单里的数字、类名、表名**，只补充叙述。

直接写 `_overview.md`（markdown）：

```markdown
# <服务名>（<领域名>）

<自然语言叙述>

## 核心接口链路
- <入口类名>...

## 数据模型
- <表名>...
```

## 输出

`<输出目录>/<领域>/<服务>/_glossary.toon`、`_overview.md`

## 门禁

`_overview.md` 里列出的入口/表，必须与 seal 输出的事实清单一致（不增不减）。
