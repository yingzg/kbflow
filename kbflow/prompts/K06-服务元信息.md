# K06 服务元信息

## 目标

为每个服务生成 3 份元信息：服务元信息（定位 + 领域覆盖 + 模块 + 入口统计）、技术配置、开发规范。

## 读什么

- `<输出目录>/service-meta/` 下的 behavior / external_dependencies / domain_division

## 步骤（对每个服务循环）

### 第 1 步：生成骨架（脚本）

```bash
python kbflow.py skeleton service-meta --domain <任意领域> --service <服务名> -o <输出目录>
python kbflow.py skeleton tech-config --domain <任意领域> --service <服务名> -o <输出目录>
python kbflow.py skeleton dev-standards --domain <任意领域> --service <服务名> -o <输出目录>
```

（service-meta/tech-config/dev-standards 是服务级产物，脚本内部不依赖 domain 过滤。）

### 第 2 步：补服务定位语义（AI）

读 `服务元信息.toon`，补全 `[待AI补充]`：
- `identity.description`：一句话服务定位
- `identity.core_responsibilities`：3-5 条核心职责

输出 json，json2toon 覆盖回 `服务元信息.toon`。

## 输出

`<输出目录>/<服务>/service-meta/服务元信息.toon`、`技术配置.toon`、`开发规范.toon`

## 门禁

服务元信息无 `[待AI补充]` 残留。
