# K07 全局导航

## 目标

生成知识库的全局入口：AI 索引（index.toon）和领域依赖全景图。

## 读什么

- `<输出目录>/service-meta/domain_division.toon`
- `<输出目录>/<领域>/` 下的各领域产物

## 步骤

### 第 1 步：生成全景图（脚本）

```bash
python kbflow.py panorama --matrix <输出目录>/service-meta/domain_division.toon --service <服务名> --out <输出目录>/领域依赖全景图.md
```

### 第 2 步：汇总 AI 索引（AI 拼装）

收集各领域/服务的产物清单，拼装 index.toon（6 个 section：services、domain_boundary_matrix、domain_files、service_files、domain_keywords、service_capabilities）。其中 `service_capabilities` 的 `capabilities`/`keywords` 从各服务概述抽取。

输出 json：

```bash
python kbflow.py json2toon --json-file index.json --out <输出目录>/ai/index.toon
```

## 输出

`<输出目录>/ai/index.toon`、`<输出目录>/领域依赖全景图.md`

## 门禁

index 的 services 非空，domain_files 覆盖全部领域。
