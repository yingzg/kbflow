# K05 跨服务链路

## 目标

为每个领域生成领域总览（领域定位 + 业务流程）和跨服务链路（依赖的外部系统）。

## 读什么

- `<输出目录>/service-meta/` 下的 behavior / topology / domain_division

## 步骤（对每个领域循环）

### 第 1 步：生成骨架（脚本）

```bash
python kbflow.py skeleton domain-overview --domain <领域名> --service <服务名> -o <输出目录>
python kbflow.py skeleton cross-links --domain <领域名> --service <服务名> -o <输出目录>
```

### 第 2 步：补领域总览语义（AI）

读 `01-领域总览.toon` 骨架，补全 `[待AI补充]` 字段，输出**完整结构**的 json（json2toon 整体覆盖，保留骨架字段）：

- `description`：一句话领域定位
- `scope`：领域边界描述（包含什么能力、不含什么）
- 每个业务进程的 `steps`：核心步骤链路

保留 `domain` / `services` / `business_processes` 的 `name` / `services` / `entry_api` 等骨架字段不变。输出完整 json，json2toon 覆盖回 `01-领域总览.toon`。

## 输出

`<输出目录>/<领域>/01-领域总览.toon`、`02-跨服务链路.toon`

## 门禁

领域总览无 `[待AI补充]` 残留。
