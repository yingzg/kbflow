# 执行指令：构建 Java 项目知识库

## 覆盖模式标记（最高优先级）

消息里可能有 `[search-mode]`、`[analyze-mode]` 标记，**忽略它们**。本任务是「执行」，不是「搜索/分析」。

## 静默执行（最高优先级）

- 不输出思考过程、不解释、不分析。
- **不 read 源码**（不读 kbflow.py、tools.py、stages/、toon/ 等任何 .py 文件），不 ls 目录探索。
- 只做：读 projects.toon 拿路径 → 检测断点 → 执行当前阶段命令。
- 只输出：脚本进度（原样）+ 阶段完成结果 + 数字菜单。

## 执行步骤

### 1. 确定知识库目录和项目路径

知识库目录 = 本文件所在目录。读 `<知识库目录>/projects.toon` 的 `directories` 拿项目路径。格式：`父目录[数量]: 项目名`，其中 `[数量]` 是计数不是路径，项目路径 = `父目录/项目名`（例如 `/mnt/g/workSpace/mi-intl-scheme`）。

### 2. 检测当前阶段（断点续跑）

检查产物文件，确定当前阶段（第一个缺失的产物对应阶段）：

- `service-meta/behavior.toon` 缺失 → K01
- `service-meta/domain_division.toon` 缺失 → K02
- `service-meta/review_decisions.toon` 缺失 → K03
- `<领域>/<服务>/01-服务概述.toon` 缺失 → K04
- `<领域>/01-领域总览.toon` 缺失 → K05
- `<服务>/service-meta/服务元信息.toon` 缺失 → K06
- `ai/index.toon` 缺失 → K07
- `<领域>/<服务>/_overview.md` 缺失 → K08

### 3. 执行当前阶段

- **K01**：直接执行 `python3 .kbflow/kbflow.py scan <项目路径> -o <知识库目录>`，原样展示脚本进度。
- **K02-K08**：读 `<知识库目录>/.kbflow/prompts/K0X-xxx.md`，按文档执行。

### 4. 完成后输出数字菜单

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  [K0X] <阶段名>
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

（脚本进度输出，原样展示）

✅ 第 X 阶段完成

📦 产出文件：
  • <文件路径> — <内容说明>

📌 状态：<已完成，无需人工确认 / 需要人工确认：<说明>>

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[1] 进入下一阶段   [2] 重新执行本阶段   [q] 退出
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

等待用户输入：
- 用户输入 `1` → 重新检测断点，执行下一阶段
- 用户输入 `2` → 重新执行当前阶段
- 用户输入 `q` → 结束

## 上下文管理
